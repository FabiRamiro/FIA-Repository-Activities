# Fundamentos de Inteligencia Artificial

Repositorio de actividades, prácticas y proyectos del curso, organizados por unidad. Cada carpeta tiene su propio README con una explicación breve y enlaces a su contenido.

| Unidad | Temas |
|---|---|
| [Unidad 1](FIA-Repositorio-Unidad1/README.md) | Historia de la IA, agentes inteligentes, preparación de datos con Bash, lógica proposicional, agentes con CrewAI, talleres de exposición y una introducción al aprendizaje automático. |
| [Unidad 2](FIA-Repositorio-Unidad2/README.md) | Búsqueda en grafos (BFS, DFS y caminos mínimos) y algoritmos genéticos. |
| [Unidad 3](FIA-Repositorio-Unidad3/README.md) | Metaheurísticas para el ciclo hamiltoniano (FHCP), KNN, recolección de datos con un crawler, perceptrones y optimización de hiperparámetros. |

## Estructura

```text
FIA-Repositorio-Actividades/
├── FIA-Repositorio-Unidad1/   10 actividades
├── FIA-Repositorio-Unidad2/   3 actividades
└── FIA-Repositorio-Unidad3/   5 actividades
```

Las actividades están numeradas en el orden en que se realizaron. Las que son proyectos de código indican en su README cómo instalar dependencias y ejecutarlas.
