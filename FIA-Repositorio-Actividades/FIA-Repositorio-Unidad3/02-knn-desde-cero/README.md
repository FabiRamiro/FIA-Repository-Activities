# KNN desde cero

Demostración del clasificador K-NN (*K-Nearest Neighbors*). No aprende parámetros: guarda los datos de entrenamiento y clasifica un punto nuevo según la clase más común entre sus K vecinos más cercanos (distancia euclidiana). El notebook lo implementa paso a paso y muestra gráficamente cómo cambia la frontera de decisión según K.

| Archivo | Contenido |
|---|---|
| [knn_demo.ipynb](knn_demo.ipynb) | Notebook con la explicación, la implementación y las gráficas. |
| [requirements.txt](requirements.txt) | Dependencias: NumPy, Matplotlib, scikit-learn y Notebook. |

```bash
pip install -r requirements.txt
jupyter notebook knn_demo.ipynb
```
