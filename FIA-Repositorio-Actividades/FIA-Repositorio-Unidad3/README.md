# Unidad 3 · Metaheurísticas y aprendizaje automático

Metaheurísticas aplicadas al ciclo hamiltoniano y fundamentos de aprendizaje automático: KNN, obtención de datos, perceptrones y ajuste de hiperparámetros.

| # | Actividad | Descripción |
|---|---|---|
| 01 | [FHCP Challenge](01-fhcp-challenge/README.md) | Proyecto en equipo: ciclo hamiltoniano con GA, SA, ACO, ABC, DE y PSO, con informe técnico y comparativo. |
| 02 | [KNN desde cero](02-knn-desde-cero/README.md) | Demostración del clasificador de K vecinos más cercanos. |
| 03 | [Dataset de anime](03-dataset-anime/README.md) | Crawler que construye un CSV de animes con título, reseña y géneros. |
| 04 | [Perceptrones: AND, XOR e Iris](04-perceptrones-and-xor-iris/README.md) | Página interactiva de estudio y hojas de cálculo con perceptrones. |
| 05 | [Hiperparámetros con AdaBoost](05-hiperparametros-adaboost/README.md) | Búsqueda en malla frente a búsqueda genética para ajustar AdaBoost. |
