# Aprendizaje automático: Iris y árbol de decisión

Clasificación de flores del dataset Iris con un árbol de decisión y un bosque aleatorio de scikit-learn. Se usan la longitud y el ancho del pétalo, se imprimen las reglas del árbol y se dibujan las regiones de decisión.
