# BASH: limpieza de clientes

Limpieza de un archivo de clientes usando únicamente comandos de Bash: se quitan duplicados, filas incompletas o con `NA` y espacios sobrantes alrededor de las comas. Después, como reto, se obtiene la lista de departamentos y las personas del departamento de ventas.

| Archivo | Contenido |
|---|---|
| [clientes_sucio.csv](clientes_sucio.csv) | Datos originales, sin limpiar. |
| [comando_realizado.txt](comando_realizado.txt) | Comandos usados (`sort`, `uniq`, `grep`, `sed`…) para limpiar los datos. |
| [dataset_limpio_final.csv](dataset_limpio_final.csv) | Resultado de la limpieza. |
| [reto.txt](reto.txt) | Enunciado y solución del reto sobre los departamentos. |
