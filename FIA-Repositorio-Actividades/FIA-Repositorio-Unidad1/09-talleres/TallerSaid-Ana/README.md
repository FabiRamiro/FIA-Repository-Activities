# Taller de procesamiento de lenguaje natural

Analizador de sentimientos sencillo para la exposición de PLN. Divide un texto en palabras y lo clasifica como positivo, negativo o neutro según listas de palabras. Sirve para mostrar de forma simple lo que en la práctica se hace con diccionarios mucho más grandes o con modelos entrenados.

| Archivo | Contenido |
|---|---|
| [pln.py](pln.py) | Tokenización y análisis de sentimiento. |

```bash
python pln.py
```
