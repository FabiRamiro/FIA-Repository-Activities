DE LA NATURALEZA AL ALGORITMO

El arte de evolucionar.

Imagina muchas distribuciones de reinas compitiendo por sobrevivir. Los tableros con menos conflictos tienen más oportunidades de reproducirse. Sus descendientes combinan posiciones y reciben pequeñas mutaciones. Eso es un algoritmo genético.

01

Selecciona

Evalúa la población y elige padres mediante torneos de aptitud.

02

Cruza

Combina un fragmento de un padre con las columnas del otro, sin repetirlas.

03

Muta

Intercambia dos columnas para explorar otras distribuciones.

El cromosoma [1, 3, 0, 2] es una solución de 4 reinas. Cada fila tiene una reina y cada columna aparece una vez. Contamos los pares que comparten diagonal. La aptitud es 1 / (1 + conflictos): su máximo, 1, significa cero amenazas.

# Algoritmo genético con elitismo
crear población de permutaciones aleatorias
evaluar conflictos de cada individuo
mientras no haya solución y quede presupuesto:
    conservar los dos mejores individuos
    seleccionar padres por torneo
    cruzar padres sin duplicar columnas
    mutar hijos intercambiando columnas
    evaluar la nueva generación
    registrar su mejor tablero

La animación muestra el mejor individuo de cada generación. Las piezas se elevan, cambian de columna y aterrizan. Los desplazamientos solo ilustran el cambio de cromosoma: no son jugadas legales de ajedrez ni muestran todos los individuos.

El elitismo conserva las mejores aptitudes. Una generación puede mantener la misma puntuación. Si se agota el tiempo o las generaciones, conservamos el mejor candidato; eso no demuestra que el problema sea imposible. N = 2 y N = 3 sí son casos imposibles conocidos.

UN PROYECTO PARA APRENDER

Lógica con alma sakura.

Sakura Queens explora N-Reinas mediante una población de tableros que evoluciona en Python.

PythonSelección por torneo, cruce de orden, mutación por intercambio, elitismo y diversidad. Transmite cada generación sin caché.

Three.jsAnima cada reina en tres fases: elevación, desplazamiento y aterrizaje. Los tableros grandes usan una superficie compartida y piezas instanciadas.

JavaScriptRecibe las generaciones, permite cancelarlas y reproduce el historial con control de velocidad.

N se escribe libremente, sin un máximo fijo como 12. El tiempo, las generaciones y la memoria disponibles limitan el cálculo real. El motor verifica un presupuesto estimado de 256 MB por búsqueda, configurable en Python. El historial del navegador también se conserva con un presupuesto y se resume si es necesario.

La búsqueda encuentra un candidato con cero conflictos o devuelve el mejor intento. No calcula la cantidad total de soluciones. N = 1 es trivial; N = 2 y N = 3 no tienen solución.

Lee README.md y solver.py para estudiar el proyecto. Three.js se incluye localmente con su licencia MIT.
