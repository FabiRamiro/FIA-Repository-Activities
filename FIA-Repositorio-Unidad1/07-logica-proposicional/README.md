# Python: lógica proposicional e inferencia

Implementación en Python de los conectivos de la lógica proposicional (negación, conjunción, disyunción…) y generación automática de sus tablas de verdad.

| Archivo | Contenido |
|---|---|
| [caso.ipynb](caso.ipynb) | Notebook con la definición y prueba de cada conectivo. |
| [main.py](main.py) | Ejemplos de evaluación booleana aplicados a la decisión de un agente. |
| [new.py](new.py) | Genera las combinaciones de verdad según la cantidad de parámetros de cada función e imprime su tabla. |

```bash
python new.py
```
