# Algoritmos genéticos

Cuatro proyectos de algoritmos evolutivos, desde un AG binario básico hasta programación genética.

| Proyecto | Descripción |
|---|---|
| [Algoritmo_Genetico](Algoritmo_Genetico/README.md) | AG con codificación binaria y real sobre funciones de prueba, con visualizadores interactivos. |
| [Algoritmo_GeneticoBueno](Algoritmo_GeneticoBueno/README.md) | **EvoLab**: programación genética para regresión simbólica (encontrar una fórmula a partir de puntos). |
| [Arbol_Expresion](Arbol_Expresion/README.md) | **Arboria**: laboratorio web de árboles de expresión en 2D y 3D, base de la programación genética. |
| [N-Reinas](N-Reinas/README.md) | **Sakura Queens**: problema de las N reinas resuelto con un algoritmo genético y animado en 3D. |
